# Platform marks

- Upwork: [SVG Viewer icon source](https://www.svgviewer.dev/s/59127/upwork).
- Freelancer: [Simple Icons 5.0.0](https://app.unpkg.com/simple-icons%405.0.0/files/icons/freelancer.js).
- Mostaql: [Wasmenia listing](https://wasmenia.com/en/logos/mostaql), served from `https://strapi.wasmenia.com/uploads/mostaql_b6533d1536.svg`.
- Khamsat: [Worldvectorlogo listing](https://worldvectorlogo.com/logo/khamsat-1), served from `https://cdn.worldvectorlogo.com/logos/khamsat-1.svg`.

Upwork and Freelancer marks are local SVG assets. Mostaql and Khamsat images use external sources with visible Arabic text fallbacks if unavailable. Platform names stay visible beside the decorative marks, and links point to the contributor's profiles. These marks identify their respective services.
